# Security Policy

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | Yes                |
| 1.x     | No (please upgrade)|

## Reporting a vulnerability

**Do not open a public GitHub issue.**

Email **lucas@example.com** (replace with your real reporting address) with:

- A description of the issue and the impact you observed.
- The smallest reproducible example you can produce.
- Affected versions and target frameworks.

You will receive an acknowledgement within 72 hours. If the report is confirmed, we will:

1. Assign a severity and target release window.
2. Prepare a fix in a private branch.
3. Coordinate disclosure and a CVE if appropriate.
4. Publish a patched NuGet release and a security advisory.

Thank you for helping keep Commander.CQRS and its users safe.
